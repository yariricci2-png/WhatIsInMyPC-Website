QUESTIONS & ANSWERS

Frequently asked questions.

Is WhatIsInMyPC free?

Yes. The application is free to download and use.

Do I need an internet connection?

An internet connection is needed to download the installer and may be needed to install required Windows components. Hardware detection itself runs locally.

Which operating systems are supported?

The current release is intended for 64-bit Windows 10 and Windows 11 computers.

Why might Windows show a security warning?

The current installer does not have a trusted digital signature. Windows may therefore display a publisher or SmartScreen warning. Always keep your security protections enabled and only obtain the application from its official release page.

Does the application improve gaming performance?

No. WhatIsInMyPC is a hardware information and educational application. It does not modify or optimize your computer.
